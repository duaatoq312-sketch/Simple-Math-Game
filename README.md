\# Math Quiz Game (C++)



A console-based math quiz application developed in C++ where the player solves a series of dynamically generated arithmetic questions. The game uses functions to organize the quiz logic, generate questions, process answers, and calculate the final result.



\## What the Game Does



The player is presented with randomly generated mathematical questions based on the selected difficulty and operation. Each answer is evaluated immediately, allowing the player to track their performance throughout the quiz.



At the end of the session, the program calculates the player's score and displays the overall result.



\## Main Features



\* Generates arithmetic questions dynamically

\* Supports multiple difficulty levels

\* Includes different mathematical operations

\* Validates and processes user answers

\* Provides immediate feedback for each question

\* Keeps track of correct and incorrect answers

\* Calculates and displays the final score

\* Runs entirely through a simple console interface
